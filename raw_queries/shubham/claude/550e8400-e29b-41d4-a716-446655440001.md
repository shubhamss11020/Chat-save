**Supermemory** is a long-term memory platform that adds persistent, self-growing memory to your AI applications. It's designed to solve a key problem with AI: providing context and persistent knowledge across conversations and sessions.

## Key Capabilities

Supermemory lets you build your own second brain for all your saved stuff — it's a ChatGPT for your bookmarks. You can:

- **Save & Organize**: Use a Chrome extension to save websites, tweets, PDFs, and other content
- **Search Semantically**: Query your memories with natural language
- **Ask Questions**: Use "Ask your supermemory" to query across your saved knowledge
- **View Connections**: Explore a graph view showing relationships between your memories

## For Developers (Relevant to Your Work)

Since you're working on MCP projects, this might be particularly interesting:

1. **API & SDKs**: The Supermemory provider is available in the `@supermemory/tools` module, and you can obtain your API key for free at console.supermemory.ai

2. **Framework Integration**: Supermemory provides wrappers for major AI frameworks like Vercel AI SDK, LangChain, LangGraph, OpenAI Agents SDK, and has a Claude Code plugin

3. **MCP Support**: There's an MCP (Model Context Protocol) installation available for Claude integration

4. **CLI**: The Supermemory CLI lets you add memories, search, manage documents, and configure projects programmatically

## Use Cases

Supermemory is a context infrastructure solution built for AI agent developers, SaaS product teams, and enterprises working with large-scale memory and data retrieval.
