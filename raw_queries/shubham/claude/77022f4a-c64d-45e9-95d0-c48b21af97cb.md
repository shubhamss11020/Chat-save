# Write a fast Fibonacci function in Python with memoization.

## User (2026-09-08T15:04:43.836Z)

Write a fast Fibonacci function in Python with memoization.

## Claude (2026-09-08T15:04:50.513Z)

Here's a fast Fibonacci function using memoization:

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fibonacci(n):
    if n < 2:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)
```

**Usage:**
```python
print(fibonacci(50))  # 12586269025 (computed instantly)
```

**Alternative with manual memoization:**
```python
def fibonacci(n, memo={}):
    if n in memo:
        return memo[n]
    if n < 2:
        return n
    memo[n] = fibonacci(n - 1, memo) + fibonacci(n - 2, memo)
    return memo[n]
```

**Or as a class:**
```python
class Fibonacci:
    def __init__(self):
        self.cache = {}
    
    def compute(self, n):
        if n in self.cache:
            return self.cache[n]
        if n < 2:
            return n
        self.cache[n] = self.compute(n - 1) + self.compute(n - 2)
        return self.cache[n]

fib = Fibonacci()
print(fib.compute(50))  # 12586269025
```

The `@lru_cache` decorator is the most Pythonic and efficient approach—it's built-in, clean, and thread-safe. It reduces time complexity from exponential O(2^n) to linear O(n).
